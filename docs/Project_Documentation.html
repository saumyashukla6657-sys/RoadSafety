GuardianNodes RoadSoS

AI-Powered Emergency Road Accident Response System

Team Name: Coders

Team Leader: Rohit Singh

Teammate: Shawsti Singh

1. Project Overview

GuardianNodes RoadSoS is an advanced, production-grade emergency response dashboard built with Streamlit. It leverages artificial intelligence to rapidly assess accident severity and dynamically coordinates emergency vehicles using traffic-aware routing and simulated mesh communications.

The system is designed to combat delayed response times in emergency situations, utilizing a combination of Natural Language Processing and graph-based routing algorithms.

2. Key Modules

A. Intelligent Triage Engine

Uses a Zero-Shot Classification model (DistilBERT via HuggingFace) to analyze incoming incident reports in natural language. It extracts key entities (casualties, vehicles, hazards) and calculates an urgency score (from Low to Critical) to prioritize emergency response efficiently.

B. Graph Routing Engine

Utilizes NetworkX to build a realistic road network graph. It applies Dijkstra's algorithm to calculate the optimal route for emergency vehicles (such as ambulances, fire engines, police cars, and hazmat units), factoring in real-time simulated traffic conditions.

C. Mesh Protocol Simulator

Simulates a robust BLE/Wi-Fi Direct mesh network. It ensures that critical data packets reach the centralized dashboard even in remote areas or during communication breakdowns by hopping through intermediary nodes with CRC validation, guaranteeing no data loss.

3. Technology Stack

  • Frontend & Dashboard: Streamlit (Python 3.11+) featuring a premium dark glassmorphism UI.
  • Machine Learning: HuggingFace Transformers, PyTorch for Zero-Shot Classification.
  • Data Structures & Routing: NetworkX for Dijkstra-based pathfinding algorithms.
  • Visualization: Plotly Express, Plotly Graph Objects for dynamic radar charts and interactive route maps.
  • Data Manipulation: Pandas, NumPy.

4. Future Scope & Impact

This system has the immense potential to be scaled nationally across all emergency control rooms. By dramatically reducing emergency response times and optimizing vehicle dispatch through predictive analytics, RoadSoS can save countless lives on the road and bring emergency infrastructure into the future.
